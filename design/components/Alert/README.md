# Inline alert

A message that belongs to a page or section and stays until the situation changes.

**Tones** — info (`info-bg` / `info-text`, `info`), success (`success-bg`, `check-circle-2`), warning (`warning-bg`, `alert-triangle`), error (`danger-bg`, `alert-circle`, `role="alert"`). Radius `radius-control`, 14px text, bold title + one sentence of help, optional secondary small action on the right (Retry, Re-screen, Open original CV).

**Use** — load errors with Retry, re-screen prompts, unreadable CVs, deadline changes. For a quick "done" use a toast; for a field problem use the field's inline error.
