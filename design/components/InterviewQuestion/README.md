# Interview question card and feedback

**Question card** — type tag (Technical `code-2`, Behavioural `message-square-text`), the question in 17px/700, a "Good answer" hint on `surface-page` with `lightbulb`, focus skill (`target`), and a delete icon button. Questions drawn from a missing requirement say so (`x-circle` "From a missing requirement"). Eight questions per generation.

**Generate questions** — secondary button with `sparkles`. While working: spinner in the button, typing dots and "Writing questions…" over skeleton cards; results enter with a stagger. Error: "Couldn't generate questions" with Retry — the rest of the page keeps working.

**Feedback form** — marked with the `hl-private` chip "Only HR can see this" (`lock`). Rating 1–5 as five 44px toggle buttons (`aria-pressed`), Strengths, Concerns, Recommendation (Offer, Reject or Another round); error "Please add a rating and a recommendation". Saved feedback appears on the candidate detail page, never in emails or candidate screens.
