# Screen · Apply form

Flow 8, steps 1–2. Form width `width-form`. Name and email prefilled, phone, then the CV dropzone (demo plays: dragging → uploading with progress → CV uploaded with Remove). Submit stays disabled until a valid PDF is uploaded, then shows a spinner while sending.

**Errors** — "Only PDF files are accepted", "File must be under 5 MB", "You have already applied to this job", "This job is closed", "Applications for this job closed on 20 Oct" (checked again on Submit). When the candidate has a default CV, the dropzone is replaced by the "Use my default CV / Upload a different CV" choice. Phone: single column, Submit full width.
