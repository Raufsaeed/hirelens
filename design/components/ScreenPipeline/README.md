# Screen · Pipeline board

Flow 20. Columns Applied, Shortlisted, Interview, Offer, Hired, Rejected on `surface-column`, each with a count chip. Cards can be dragged (tilt + lift, target column tints, card fades in, count bumps) or moved with the "Move to" select. Hired fires one confetti burst. A toast confirms every move.

In the product: moving to Interview opens the schedule form; moving to Rejected asks to confirm; a failed move returns the card with "Couldn't move this candidate, try again". "Close job" confirms with a dialog. The board scrolls sideways inside its own box on small screens.
