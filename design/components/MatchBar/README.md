# Match bar and rubric

**Match bar** — requirements found ÷ total requirements, as a percentage. Track `surface-sunken` 8px (6px `--sm` in tables), fill `primary-soft` → `primary`, value in `numeric` with tabular figures and a "4 of 5 found" caption. `role="meter"` with `aria-valuenow`. Fills from 0 in 600ms when results arrive.

**Rubric breakdown** — six criteria, always in this order, marks out of max, a thin `primary` bar and one plain-language reason from the AI:
Skills match /35 · Experience /40 · Education /10 · Structure and formatting /5 · Contact info, summary and links /5 · Grammar and clarity /5 = 100.

**Rules** — numbers are calculated in code from the AI's per-item judgements, so the same CV gets a steady score. Reasons quote or summarise the CV; never comment on name, age, gender, religion or city. Candidates never see this block.
