# Status timeline

What a candidate sees on their application: the steps so far, never a score or AI result.

**Steps** — Applied (`send`) → Shortlisted (`star`) → Interview (`calendar-clock`) → Offer (`handshake`) → Hired (`party-popper`). Done steps: `primary` dot and connecting line. Current step: `surface` dot with `primary` ring and a 4px `primary-tint` halo; when it is new it pops in once. Upcoming: grey outline dot, `ink-muted` label.

**Interview** — an `info-bg` panel with date (`calendar`), time (`clock`), meeting type (`video`) and a full-width primary "Join meeting" link (opens in a new tab).

**Final states** — Hired: `success` dot with a warm line. Rejected: `danger-bg` dot with `circle-slash`, titled "Not selected" with a kind, short sentence. Withdrawn: dashed muted dot.

**Phone** — single column, dots on the left, text wraps; no horizontal scroll at 360px.
