Flow 14, steps 2–4. On load it shows "AI is checking this CV…" then plays the results moment: the ring draws to 74 while the number counts, the match bar fills to 80%, rubric bars fill and the found tags pop in one by one.

Header: avatar, name, pipeline badge, job, applied date · Open original CV, Reject (danger ghost, confirms), primary Shortlist (badge cross-fades to Shortlisted, toast). AI note "AI suggestions are advice only — you make the decision". Left column: score card (ring, band, match, AI summary, six-part rubric). Right: tabs — Requirements (found with CV evidence; missing with a hint), Notes (HR-only, name + time), Interview.

**States** — skeleton of score panel; "Couldn't load this candidate" + Retry; "Screening pending" + Retry screening; "CV could not be read" + Open original CV.
