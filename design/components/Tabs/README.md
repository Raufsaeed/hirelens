# Tabs

**Underline tabs** — 44px tabs, 14/700, `ink-muted`; selected `primary` with a 3px `primary` indicator that slides to the selected tab (300ms `ease-out`). Optional 16px leading icon and a count chip. Panels fade up 8px on change. Keyboard: Left/Right arrows move and select; only the selected tab is in the tab order. Overflowing tabs scroll sideways inside the bar.

**Segmented control** — for two or three peer choices such as Sign up / Log in and All jobs / one job: `surface-sunken` track, `surface` sliding thumb with `shadow-card`.

**Use** for switching views of the same object (candidate detail: AI review, CV, Notes, Interview). Don't use tabs for steps in a process.
