# Empty state

Shown when a list has nothing yet. It explains why and offers the next step, so an empty screen never looks broken.

**Anatomy** — 88px `primary-tint` circle with a 44px icon (stroke 1.5) · title 17/700 · one sentence in `ink-muted` (max 360px) · one button (primary when it starts the main task, secondary when it undoes a filter). 48px padding, centred.

**Copy from the flows** — "You have no jobs yet" + Post your first job (`briefcase`); "No one has applied yet. Share your job link" + Copy job link (`users`); "No candidates match these filters" + Clear filters (`sliders-horizontal`); "You haven't applied to any jobs yet" + Browse jobs (`file-text`); "You haven't saved any jobs yet" (`bookmark`); "ABC Tech has no open jobs right now" (`building-2`); "Not enough data yet" (`bar-chart-3`); "No candidates found for 'xyz'" (`search`).
