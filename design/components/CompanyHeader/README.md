# Company header

Top of the public company page (`/companies/abc-tech`). Public: never show HR names, applicant counts or any candidate data.

**Anatomy** — 72px logo (or monogram) · `page-title` name · meta row: `map-pin` location, `globe` website link, `users` size, `briefcase` open jobs count (Open jobs only) · About us paragraph (max ~640px) · "See open jobs" (scrolls to the list) and "Visit website" (`external-link`, opens a new tab).

**Phone** — single column: logo, name, meta wrapping onto lines, buttons full width.

**Empty** — when no jobs are open, the jobs list below shows the empty state "ABC Tech has no open jobs right now". **Error** — "This company could not be found".
